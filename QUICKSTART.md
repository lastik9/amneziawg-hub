# ⚡ Быстрый старт — хаб за один скрипт

Короткий путь для тех, кто доверяет `scripts/awg-hub.sh`. Полное объяснение каждого шага — в [`docs/01-server-prep.md`](docs/01-server-prep.md) (укрепление ОС) и [`docs/02-server-awg.md`](docs/02-server-awg.md) (AmneziaWG + хаб).

> **Пункт 1 меню (`bootstrap`) делает всё сразу:** обновление системы → снос Docker → установка AmneziaWG → `sysctl` (forward + IPv6 off) → подъём `awg0` → ufw + fail2ban → SSH-хардненинг. То есть `01` **и** `02` за один прогон, до рабочего хаба с готовым публичным ключом. Скрипт идемпотентный — можно перезапускать.

---

## Схема

**Голый сервер → залил SSH-ключ → скачал скрипт → пункт 1 → Enter по дефолтам.**

### 0. Что нужно

- VPS с **Ubuntu 24.04**, **белым IPv4 без NAT**, доступом `root`.
- Порт **`443/udp`** свободен и не режется на площадке (маскировка под QUIC).

### 1. Залей SSH-ключ (со своего ноута)

**Способ А — `ssh-copy-id` (проще всего):**

```bash
ssh-copy-id -i ~/.ssh/id_ed25519.pub root@<SERVER_IP>
ssh root@<SERVER_IP>        # должно пустить без пароля
```

**Способ Б — вручную через Vim** (если `ssh-copy-id` нет или хочешь видеть файл):

Сначала на **ноуте** покажи публичный ключ и скопируй строку целиком (от `ssh-ed25519` до метки):

```bash
cat ~/.ssh/id_ed25519.pub
```

Теперь на **сервере** открой файл ключей:

```bash
mkdir -p ~/.ssh && chmod 700 ~/.ssh
vim ~/.ssh/authorized_keys
```

В Vim:

1. `G` (заглавная) — прыгнуть в конец файла (встанешь на последней строке, если ключи уже есть).
2. `o` (строчная) — новая строка под текущей + режим ввода (старые ключи не трогаются).
3. Вставь ключ: **Cmd+V** (в Terminal.app; если не сработало — правый клик → Paste).
4. `Esc` — выйти из ввода.
5. `:wq` + Enter — сохранить и выйти. (Напортил — `:q!` выйдет без сохранения.)

Проверь права и что ключ на новой строке:

```bash
chmod 600 ~/.ssh/authorized_keys
cat ~/.ssh/authorized_keys        # каждый ключ — отдельной строкой, старые на месте
```

Затем проверь вход по ключу с ноута: `ssh root@<SERVER_IP>` — должно пустить без пароля.

> Не строго обязательно заранее: скрипт на шаге хардненинга **сам предложит вставить ключ** (одной строкой в промпт), а без ключа **оставит вход по паролю** (не залочит). Но с ключом на месте хардненинг реально отключит пароль — так безопаснее.

### 2. Скачай скрипт и запусти (на сервере, под root)

```bash
curl -fLO https://raw.githubusercontent.com/lastik9/amneziawg-hub/main/scripts/awg-hub.sh
chmod +x awg-hub.sh
sudo bash awg-hub.sh        # → пункт 1) Установить / пересобрать хаб
```

> Если `raw.githubusercontent.com` не открывается на площадке — скопируй файл с ноута: `scp scripts/awg-hub.sh root@<SERVER_IP>:~/`.

### 3. Прожимай Enter по дефолтам

Скрипт спросит по порядку (в скобках — что принять Enter'ом):

| Промпт | Дефолт |
|---|---|
| Режим (1 пересобрать / 2 новый) | `2` на свежем сервере |
| WG-подсеть | `10.0.0.0/24` |
| Адрес сервера в WG | `10.0.0.1` |
| UDP-порт | `443` |
| Публичный endpoint | **определяется сам** (твой белый IP) |
| Профиль обфускации (12 параметров) | из хэндоффа, байт-в-байт |
| Ключ сервера | сгенерирует новый |
| SSH-порт | `22` |
| `apt upgrade?`, `снести Docker?`, `хардненинг?` | `Y` |

На выходе — блок «Хаб готов ✅» с **endpoint'ом и публичным ключом** сервера (понадобится пирам).

> Забыл ключ или закрыл окно? Переспросить публичный ключ хаба в любой момент:
> ```sh
> awg show awg0 public-key
> ```

### 4. Добавь пиров

`sudo bash awg-hub.sh` → **пункт 2 (Управление пирами)**:

- **+ Клиент** (Mac/телефон) — генерит ключи, выдаёт `.conf` + QR.
- **+ Site** (OpenWrt со своей LAN-подсетью) — вводишь его публичный ключ, получаешь UCI-блок для роутера.

> **Форвардинг пир↔пир ставится сам.** `bootstrap` при настройке файрвола выполняет `ufw route allow in on awg0 out on awg0` — без этого узлы видели бы только хаб, но не друг друга и не клиентов. Руками добавлять не нужно; проверить, что правило на месте: `iptables -L ufw-user-forward -n -v | grep awg0` (флаг `-v` обязателен — без него колонки интерфейсов не печатаются и grep даёт пусто).

## Про обновление ядра (важно, но не страшно)

Если `apt full-upgrade` подтянул новое ядро (частый случай на свежем образе), **ребут посреди прогона не нужен**: пакет `amneziawg-dkms` собирает модуль сразу под **оба** ядра — запущенное и новое, — поэтому `modprobe amneziawg` проходит и хаб поднимается на текущем ядре без перезагрузки.

**После** успешного прогона сделай плановый `reboot` в удобный момент — чтобы переехать на свежее ядро (с обновлённым микрокодом и т.п.). Интерфейс `awg0` поднимется сам (`systemctl enable` уже сделан); проверить после ребута:

```bash
uname -r                          # новое ядро
awg show awg0                     # интерфейс снова поднят
systemctl is-active awg-quick@awg0
```

## ⚠️ Если что-то пошло не так

- **Держи второе SSH-окно** открытым до конца прогона — на случай нештатной ситуации с sshd. Хардненинг делает `reload` (не рвёт сессию) и проверяет `sshd -t` с откатом, но перестраховаться дёшево.
- **Вход по ключу не проверил заранее** — сразу после «PasswordAuth=off» открой новое окно и войди по ключу. Пустило — старую сессию можно закрывать; нет — чинишь через неё (`00-hardening.conf`).
- **Сменил SSH-порт** (не 22) — скрипт откроет его в ufw до хардненинга, но не забудь ходить на новый порт в свежем окне.
- **Не уверен в шаге** — иди по полному мануалу `01`/`02`, там каждое действие объяснено.
