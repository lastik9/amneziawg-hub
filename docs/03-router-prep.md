# 03 · Подготовка роутера (site-узел)

> 🚧 **Следующий шаг.** Здесь будет пошаговая подготовка OpenWrt-роутера как site-узла меша: прошивка/пакеты, интерфейс AmneziaWG, профиль обфускации, маршрутизация LAN, обход перехватчика (Clash/ssclash или podkop/sing-box), MTU.

Планируемая структура:

1. **Требования и прошивка** — OpenWrt 23/24/25, модель, модемное подключение.
2. **Пакеты** — `amneziawg`, зависимости, luci-компоненты.
3. **Интерфейс `awg0`** — UCI: адрес узла в WG-сети, MTU `1280`, профиль обфускации (тот же, что на хабе).
4. **Peer к хабу** — публичный ключ сервера, `endpoint:443`, `allowed_ips` (internal-only), `persistent_keepalive`.
5. **Маршрутизация LAN** — чтобы устройства за роутером ходили в меш.
6. **Обход перехватчика** — Clash (`ssclash`) для деревни / podkop (`sing-box`) для города; разные площадки — разные DPI.
7. **Проверка** — handshake, ping между узлами, замер скорости.

Параметры конкретного узла (публичный ключ, WG-адрес, `allowed_ips`, UCI-блок профиля) выдаёт `scripts/awg-hub.sh` → меню пиров → «+ Site».
