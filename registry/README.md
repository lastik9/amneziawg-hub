# Реестр пиров хаба (публичная копия)

Источник истины: `/etc/awg-hub/peers/*.peer` на хабе (138.16.178.138), режим `0600`.
В git копии лежат как `registry/hub-peers/<name>.peer.pub` (см. ниже).
Здесь версионируются ТОЛЬКО публичные поля: NAME/TYPE/PUBKEY/WG_IP/SUBNET/DESC.

**PSK замаскирован** как `PSK="<redacted>"` и в git НЕ хранится (секрет).
Плейсхолдер невалиден как ключ — эту копию нельзя вслепую применить как боевой конфиг.

Обновлять при ротации ключей/добавлении пиров: заново снять маску на хабе и скопировать.
Секреты (`server.key`, `hub.env`, реальные PSK) в git не кладём никогда.
