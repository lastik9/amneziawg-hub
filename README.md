# awg-mesh

Меш-сеть на **AmneziaWG**: центральный хаб на VPS + роутеры-узлы на площадках + роуминг-клиенты. Один зашифрованный, DPI-устойчивый туннель связывает частные LAN-подсети в общую сеть.

## Что это

- **Хаб на VPS** с белым IP, порт `443/udp` (маскировка под QUIC).
- **Site-узлы** (OpenWrt-роутеры) со своими LAN-подсетями.
- **Роуминг-клиенты** (ноут/телефон) через AmneziaVPN.
- Единый профиль обфускации AWG 2.0 на всех участниках.

Подробнее — [`docs/00-overview.md`](docs/00-overview.md).

## Быстрый старт

```bash
git clone <URL> awg-mesh && cd awg-mesh
```

Порядок работ:

1. **[Подготовка сервера](docs/01-server-prep.md)** — обновление, SSH-ключи, отключение пароля, ufw, forwarding.
2. **[AmneziaWG на сервере](docs/02-server-awg.md)** — установка и хаб.
3. **[Подготовка роутера](docs/03-router-prep.md)** — site-узлы _(следующий шаг)_.

Всё автоматизировано в интерактивном скрипте:

```bash
sudo bash scripts/awg-hub.sh
```

Меню: bootstrap хаба · управление пирами (клиент → `.conf` + QR; site → UCI-блок) · статус.

Приватные ключи, `.peer`, `hub.env` и клиентские `.conf` **не коммитятся** (см. [`.gitignore`](.gitignore)). В репозитории — только код и обезличенные примеры.
